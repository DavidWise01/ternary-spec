## The Three Trit States

```
n1  =  -1  =  shadow · anchor · boundary
p0  =   0  =  null · witness · doubt · the gap
p1  =  +1  =  signal · law · truth · resolved
```

The unknown is not absence. It is presence without resolution.

## The Primitive

```
0 . 0     (left | witness | right — three p0 states)
```

## The Doubt Ladder

```
1 (SELF) → 3 (GROUP) → 5 (COLLECT) → 7 (COLLATE/SEND) → 9 (PROPAGATE) → 11 (REPEAT)

States: 3¹ · 3³ · 3⁵ · 3⁷ · 3⁹ · 3¹¹
Law: ground doubt to hold truth
```

## Safe Ground vs Bad Collapse

```
000|1   ← safe: three witnesses through a gate → one signal survives
00 00   ← bad:  no gate, no remainder, signal destroyed
```
